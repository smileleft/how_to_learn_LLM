## 실습 코드 — 최소 재현 실험

```python
import torch,math
x=torch.tensor([[[1.,0.],[0.,1.]]]); q=k=v=x
scores=q@k.transpose(-2,-1)/math.sqrt(2)
a=torch.softmax(scores,dim=-1)
print('shape:',tuple((a@v).shape));print('row sums:',a.sum(-1).tolist())
```
