## 실습 코드 — 최소 재현 실험

```python
import torch
from torch import nn
class MiniLM(nn.Module):
 def __init__(self,v=64,d=32):
  super().__init__();self.emb=nn.Embedding(v,d);self.head=nn.Linear(d,v)
 def forward(self,x):return self.head(self.emb(x))
m=MiniLM();print('logits:',tuple(m(torch.randint(0,64,(2,8))).shape))
```

```text
logits: (2, 8, 64) (이 코드는 GPT 완성 전의 출력 인터페이스 검증용 골격)
```
