## 실습 코드 — 최소 재현 실험

```python
import torch
x=torch.tensor([1.,2.,3.],requires_grad=True)
y=(x*x).sum();y.backward()
print('loss:',y.item());print('grad:',x.grad.tolist())
```

## 예상 실행 결과

```text
loss: 14.0 / grad: [2.0, 4.0, 6.0]
```

> 실제 학습 시간, 부동소수점 수치, 메모리 및 처리량은 실행 환경에 따라 달라짐. 표시한 값이 가정/예시인 경우 반드시 실측으로 대체할 것.
