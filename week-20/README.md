## 실습 코드 — 최소 재현 실험

```python
import time
start=time.perf_counter();time.sleep(.02)
print('latency_ms >= 20:',(time.perf_counter()-start)*1000>=20)
```

## 예상 실행 결과

```text
latency_ms >= 20: True (OS 스케줄링에 따라 변동)
```

> 실제 학습 시간, 부동소수점 수치, 메모리 및 처리량은 실행 환경에 따라 달라집니다. 표시한 값이 가정/예시인 경우 반드시 실측으로 대체하세요.
