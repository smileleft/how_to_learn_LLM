## 실습 코드 — 최소 재현 실험

```python
from dataclasses import dataclass
@dataclass
class GenerateRequest:
 prompt:str
 max_tokens:int=128
 temperature:float=0.7
print(GenerateRequest('알람을 설명해 줘'))
```

## 예상 실행 결과

```text
GenerateRequest(prompt='알람을 설명해 줘', max_tokens=128, temperature=0.7) (C++ 인터페이스 설계 전 API 계약 검증)
```

> 실제 학습 시간, 부동소수점 수치, 메모리 및 처리량은 실행 환경에 따라 달라집니다. 표시한 값이 가정/예시인 경우 반드시 실측으로 대체하세요.

## 주말 통합 과제

1. 최소 실험을 독립적으로 다시 작성하고 각 단계에 주석을 추가합니다.
2. 입력 크기 또는 설정을 2가지 이상 바꾸어 결과 차이를 표로 기록합니다.
3. 해당 주제의 기능을 이전 주 프로젝트와 연결합니다. 통합이 불가능한 경우 함수/API 계약과 테스트를 작성합니다.
4. 실행 명령, 소요 시간, 오류 및 해결 방법을 `NOTES.md`에 기록합니다.
5. `pytest` 기반 테스트를 최소 2개 작성합니다(정상 동작 및 경계 조건).
